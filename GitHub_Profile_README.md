## About Me

I am an undergraduate student majoring in Cybersecurity at Guangzhou University, interested in graph deep learning, federated learning, multimodal learning, and reliable LLM Agent systems.

My recent work focuses on building practical AI Agent applications with tool calling, RAG, MCP, memory, streaming interaction, and safety control. I also work on graph learning research for pattern densest subgraph mining under subgraph matching.
